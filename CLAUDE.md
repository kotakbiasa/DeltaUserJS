# DeltaUserJS — AI Agent Guide

Panduan untuk agen AI (Claude, dan lainnya) ada di satu tempat saja:

**→ [AGENTS.md](./AGENTS.md)**

File ini sengaja dibuat tipis. Sebelumnya `CLAUDE.md` adalah salinan penuh
`AGENTS.md`, lalu keduanya menyimpang: salinan ini sempat menunjuk path modul
yang sudah pindah dan mendaftarkan dependency yang tidak pernah ada di
`package.json`. Satu sumber kebenaran menghindari pengulangan itu.

Perbarui `AGENTS.md`, jangan file ini.
