# Arsip review dan roadmap

Direktori ini menyimpan dokumen historis yang sebelumnya berada di root repository.
Dokumen-dokumen tersebut sengaja tidak dihapus agar keputusan dan konteks lama
tetap dapat ditelusuri, tetapi sebagian path, milestone, dan statusnya tidak lagi
mencerminkan source saat ini.

Gunakan dokumentasi aktif berikut sebagai acuan:

- [`../../architecture.md`](../../architecture.md)
- [`../../security.md`](../../security.md)
- [`../../../README.md`](../../../README.md)

Isi arsip tidak menjadi quality gate dan tidak dipakai oleh runtime, build, test,
atau deployment.

| `ARCHITECTURE.md` | Peta struktur lama; digantikan oleh `docs/architecture.md` |
| `PROJECT.md` | Roadmap/milestone lama |
